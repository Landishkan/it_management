# it_management
Программный комплекс для автоматизации бизнес-процессов IT-компании: управление заказами, задачами и взаимодействием с клиентами через единый REST API.
Полнофункциональная система управления заказами на разработку программного обеспечения. Проект включает REST API на ASP.NET Core, десктопное приложение для сотрудников (WPF) и веб-кабинет для клиентов.

## 📋 О проекте

Программный комплекс автоматизирует бизнес-процессы управления заказами: от оформления клиентом заявки до завершения разработки и сдачи проекта. Система обеспечивает разграничение доступа для различных ролей пользователей и работает с облачной базой данных PostgreSQL.

## ✨ Ключевые возможности

### 🔐 Безопасность и авторизация
- JWT-аутентификация с ролевой моделью доступа
- 4 уровня доступа: `Client`, `Manager`, `Developer`, `Admin`
- Изоляция данных на уровне запросов к БД
- Защита от эскалации привилегий (роль Admin назначается только через SQL)

###  Управление заказами
- Создание и отслеживание заказов клиентами
- Назначение исполнителей и декомпозиция задач
- Обновление статусов в реальном времени
- История изменений по каждому заказу

### 👥 Ролевой интерфейс
- **Клиент:** оформление заказов, просмотр статуса своих проектов
- **Менеджер:** управление всеми заказами, распределение ресурсов
- **Разработчик:** просмотр назначенных задач, обновление прогресса
- **Администратор:** полное управление системой

## 🏗 Архитектурные решения

### Асинхронное программирование
Все операции ввода-вывода (работа с БД, сетевые запросы) реализованы через `async/await` для:
- Предотвращения блокировки потоков
- Обеспечения высокой производительности под нагрузкой
- Эффективной обработки множества параллельных запросов

### Работа с данными
- **Основная логика:** Entity Framework Core для удобной поддержки кода
- **Критические операции:** Прямые SQL-запросы для инициализации и оптимизации
- **Структура БД:** Реляционная модель с поддержкой ACID, использование JSONB для гибких данных

### Интеграция с клиентскими приложениями
API спроектировано с учетом:
- CORS для безопасного междоменного взаимодействия
- Стандартизированных форматов ответов (JSON)
- Корректной обработки ошибок с понятными статус-кодами
- Stateless архитектуры (JWT не требует хранения сессий на сервере)

## 🚀 Установка и запуск

### Требования
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- PostgreSQL (локальный или облачный)
- Git

### Пошаговая инструкция

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Landishkan/it_management.git
   cd it_management
   ```

2. **Настройте подключение к базе данных:**
   
   Откройте файл `OrderManager.App/appsettings.json` и укажите вашу строку подключения:
   ```json
   "ConnectionStrings": {
     "DefaultConnection": "Host=your_host;Database=your_db;Username=your_user;Password=your_password"
   }
   ```

3. **Установите зависимости и примените миграции:**
   ```bash
   dotnet restore
   dotnet ef database update --project OrderManager.App
   ```

4. **Запустите приложение:**
   ```bash
   dotnet run --project OrderManager.App
   ```

5. **Откройте Swagger для тестирования API:**
   ```
   https://localhost:5000/swagger
   ```
   *(порт может отличаться в зависимости от вашей конфигурации)*

### Первый запуск

- Используйте учетные данные, предоставленные администратором
- Для создания первого администратора выполните SQL-скрипт инициализации в базе данных
- После входа система автоматически получит JWT-токен для последующих запросов

## 📚 API Документация

Полная интерактивная документация доступна через **Swagger UI** после запуска приложения.

### Основные эндпоинты

#### Аутентификация
- `POST /api/auth/login` — Вход в систему, получение JWT-токена
- `POST /api/auth/register` — Регистрация нового пользователя (роль Client)

#### Заказы (Orders)
- `GET /api/orders` — Получить список заказов (фильтрация по роли)
- `GET /api/orders/{id}` — Получить детали заказа
- `POST /api/orders` — Создать новый заказ (Client/Manager)
- `PUT /api/orders/{id}` — Обновить заказ (Manager)
- `DELETE /api/orders/{id}` — Удалить заказ (Admin)

#### Задачи (Tasks)
- `GET /api/tasks` — Список задач (фильтрация по назначению)
- `POST /api/tasks` — Создать задачу в рамках заказа
- `PUT /api/tasks/{id}/status` — Обновить статус задачи

### Пример запроса

```bash
# Авторизация
POST https://localhost:5000/api/auth/login
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "securePassword123"
}

# Получение токена в ответе и использование:
GET https://localhost:5000/api/orders
Authorization: Bearer YOUR_JWT_TOKEN_HERE
```

## 🔒 Безопасность

- **JWT токены:** Хранятся в оперативной памяти клиента, не сохраняются на диск
- **Ролевая модель:** Строгое разграничение доступа на уровне контроллеров и сервисов
- **Валидация данных:** Проверка всех входящих данных через Data Annotations
- **SQL-инъекции:** Защита через параметризованные запросы EF Core
- **HTTPS:** Принудительное использование защищенного соединения
